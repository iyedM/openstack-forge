# Support

OpenStack Forge is currently in an early development stage, and support is primarily community-driven.

## How to get help

- Use the GitHub issue tracker for bug reports, questions, and feature requests.
- Check the documentation in `docs/` before opening a new issue.
- Provide as much context as possible, including the command or workflow that triggered the issue and the relevant environment details.

## Before opening a request

- Review the existing issues to avoid duplicates.
- Include minimal reproduction steps.
- Do not share credentials, secrets, or production-sensitive configuration.

## Scope

This project does not yet provide production-grade operational support. Requests should focus on project structure, usability, documentation, and testability.
